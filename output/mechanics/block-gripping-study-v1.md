# PLA 方块质量、导料与两种取块工况核算

状态：依据本地比赛规则、用户给定材质及旧概念尺寸的设计核算；不是实物测试或可加工图。日期：2026-09-16。

## 1. 结论

- 按规则图的六面开孔框架、普通 PLA 参考密度 1.24g/cm³、棱条全部实心且不计倒角计算，单块约 **39.7g**，8 块约 **317g**。这是该密度下的未倒角实心参考上限，不是赛事道具的实测质量。
- 导料槽材质未定，不能给出唯一摩擦系数。起滑条件是 `tan(倾角) > 静摩擦系数`；30°只适用于实测静摩擦系数低于约0.577、且没有卡边等额外约束的情况。
- 洞口取块：左右薄夹指有尺寸空间，采用“夹紧、直线退车拉出、再抬臂”值得制作样机验证；孔口尺寸的方向、夹爪姿态和完整运动包络仍须确认。
- 挂架取块：夹爪必须让方块沿杆滑到自由端。旧方案仅检查250mm高度，遗漏了挂杆下的150mm台阶。**转轴高85mm、有效半径180mm的旧布局，不能按图示直接从地面越过台阶夹取杆根处的方块。** 必须先解决接近路线与碰撞，再冻结机械结构及PCB空间。

## 3. 质量计算

忽略倒角时，棱条厚度 `t = (40−20)/2 = 10mm`。将框架分成8个角块和12段不重复计角的棱条：

```text
V = 8×10³ + 12×20×10²
  = 32,000mm³ = 32cm³
m = 32×1.24 = 39.68g
8m = 317.44g
```

等价表达式为 `40³−3×40×20²+2×20³`，即扣除三个相交的正方形贯通孔。直接使用 `40³−20³` 会把六面的开孔算成实体，得到错误的56cm³。

倒角会减小体积；非实心打印也会降低质量。**不能把39.68g直接乘切片软件的填充率**：外壁、顶底层仍按实际壁厚打印，只有内部区域应用填充率。没有STL、倒角尺寸和切片设置时，不应给实际道具编造“精确重量”。首轮普通PLA道具负载估算可用40g/块，取到样件后称重修订；含高密度填料的特殊PLA不受这一参考上限保证。

40g对应重力约 `0.04×9.81 = 0.392N`。在180mm水平力臂末端，它自身贡献约 `0.04×18 = 0.72kgf·cm` 的静态转矩；夹爪、舵机、臂自重和加速度另算，不能由此直接判定MG995整机余量。

## 4. 摩擦与导料槽

### 4.1 可计算的条件

在小车静止、方块只接触槽底、没有夹边或挂住的简化模型中：

```text
法向力 N = mg cosθ
沿坡重力 = mg sinθ
最大静摩擦力 = μs mg cosθ
自行起滑要求：tanθ > μs
已滑动时：a = g(sinθ − μk cosθ)
```

静摩擦力不是始终等于其最大值。μs是静摩擦系数，μk是动摩擦系数，二者不能无条件混用。质量在起滑条件中抵消，因此打印更轻不自动意味着可以用更平的导料槽。

下表仅是**假设摩擦系数的敏感性计算**，不是PLA、亚克力或金属的材料实测表。

| 假设μs | 理论临界角，超过才起滑 | 40g方块在30°坡上的最大静摩擦力 |
|---:|---:|---:|
| 0.20 | 11.3° | 0.068N |
| 0.30 | 16.7° | 0.102N |
| 0.40 | 21.8° | 0.136N |
| 0.50 | 26.6° | 0.170N |
| 0.60 | 31.0° | 0.204N |

40g方块在30°坡上，沿坡重力约0.196N、法向力约0.340N。因此μs=0.4时可以起滑，μs=0.6时可能静止；30°不是尚未选材情况下的保证值。

### 4.2 对简单料槽的建议

- 先做可调20–35°的单段试验槽，再确定固定角度；这个范围是试验起点，不是已验证设计要求。
- 底面连续平整，接缝齐平，螺钉不突出。方块孔边挂在台阶、接缝或另一块的棱条上属于几何卡住，加大坡度或套用摩擦公式不一定能解决。
- 夹爪接触垫需要防滑；槽底需要顺畅滑动。两者不必使用同一种表面。打印支架配平整薄塑料板、光滑板材或直接打印槽均可先用实物比较，暂不指定某材料必然具有某摩擦系数。
- 单列槽净宽44–46mm可作为对正摆放的试件起点，入口做较宽的导向过渡。40mm方块在槽底平面内偏转5°时横向包络43.3mm，偏转10°时已达46.3mm；46mm槽不能保证接住任意倾斜投下的方块。
- 先验证一层排队和连续入料。倾斜槽不自动实现2×2×2两列两层堆叠；单轴翻臂仍不能独立选择左右位置。
- 先在水平场地停车装料。坡道上的车身俯仰会改变槽对水平面的实际倾角，制动、转弯和侧壁挤压也超出上述简化模型。

### 4.3 最小实测方法

用真实方块放在候选槽底材料上，缓慢抬高板的一端，记录从静止开始持续滑动的角度α，取 `μs≈tanα`。改变方块接触面与打印纹路方向，每种重复至少5次；用观测到的较大起滑角再加约3–5°作为下一轮试验角度，而非最终可靠性保证。例：试板长200mm、抬高端到水平面的高度为h时，`sinα=h/200`，或用手机倾角仪直接读角。随后必须用完整槽测试夹边、卡缝、入料碰撞和满载停止，不只测试一块在平板上滑动。

## 5. 洞内夹取

### 5.1 尺寸可容纳薄夹指，但还不是整机可行性证明

按洞口宽70、高50mm，方块宽40、高40mm计算：左右各剩15mm；若方块落在底面，则顶部约10mm，底部没有保证间隙。

一组首轮试验尺寸为：夹爪张开内距50mm、每侧夹指厚4mm，张开外宽58mm；在70mm洞口两侧各剩6mm。橡胶垫、转轴和连杆必须算入实际包络，不能仅量两片塑料指。进入洞内部分的总宽可先控制在60–64mm内、高度控制在44mm内，SG90及较大传动机构留在洞外。

方块側面中心是20mm孔口。夹指应接触完整的棱条，优先夹靠洞口的两条前侧竖棱；从前表面向内约5–8mm的接触位置可作为试验起点，具体避开倒角并核对打印实物。伸入太深、正对侧孔中心可能夹空。不把底部托钩作为取块前提。

若参考质量40g、假设夹垫摩擦系数0.5，两个夹指对称压紧，单侧正压力满足 `2μN ≥ mg`：静止悬空时每侧约需0.392N，取两倍重力的简化动态工况则每侧约0.785N。这说明方块自重不大，但不证明SG90一定提供该夹力；实际夹力取决于连杆比例、夹指长度、垫片摩擦和舵机供电。水平拉出时还应克服洞底摩擦，碰壁卡住不属于正常摩擦负载。

### 5.2 动作顺序

1. 在洞外对正，低位夹爪保持适合入口的姿态，张开后从左右间隙进入。
2. 夹住两条实体棱，翻臂角度暂时保持不变。
3. 小车直线后退，让方块完全离开洞口；从初始前表面齐洞口算，拉出行程至少40mm，首轮可留45–50mm。
4. 方块和夹指退出洞顶约束后，再抬臂送入料槽。

不能刚夹住就抬臂：50mm高的洞口对40mm方块余量很小，翻转轨迹会碰洞顶。旧稿中的平行四边形保持姿态结构，在简化版里没有确认保留；若夹爪刚性装在单臂上，其姿态会随臂角变化，必须在CAD或样板中检查低位开合、进入和退车的整个包络。场地图的接近方向与车体停车空间也需一起检查。

## 6. 挂杆取块

### 6.1 拿取方向

20mm孔口与14mm杆径有6mm名义总间隙；“每边3mm”只适用于理想居中，悬挂时实际会与孔边接触。它只能说明存在穿杆余量，不能保证倾斜拉动不咬杆。

图示方块在靠墙杆根。应从外侧实体棱夹住，尽量保持孔轴与杆轴对齐，沿杆向自由端滑动，整块越过自由端后再抬起或翻回。假设近侧面初始贴墙，方块占杆轴方向0–40mm，而杆到150mm处终止，则方块近侧面需要移动超过150mm才完全脱杆；不能只把方块中心移到杆尖处就抬起。不可向上硬提让实体框架穿过杆，也不能靠扭斜后强拉来代替对正。

### 6.2 旧180mm臂长为什么不能仅凭高度判为可行

未倒角、孔面竖直的理想悬挂状态，杆顶高度257mm与孔顶接触，方块中心约247mm；实际姿态、倒角会使其变化，所以按247–250mm核查。

```text
转轴高度 z0 = 85mm
有效半径 L = 180mm
目标高度 z ≈ 247mm
此高度下能保留的水平伸距
  = sqrt(180² − (247−85)²)
  = 78.5mm
```

若目标中心取250mm，水平伸距只剩71.9mm。虽然最高点 `85+180=265mm` 大于挂杆高度，但这是忽略障碍的点位可达上限。

按图示杆根靠墙、下方台阶向外延伸300mm，且方块近侧面靠墙这一估算位置：从台阶外端到方块中心约280mm。即便乐观地把转轴放在台阶外沿，几何距离也约 `sqrt(280²+162²)=323.5mm`，已超过180mm。更关键的是转轴低于150mm台阶顶，直臂还可能穿过台阶实体；323.5mm是忽略碰撞后的距离下界，**不是建议换成324mm直臂即可解决**。

若从台阶侧边接近，并按杆轴在300mm宽台阶中线估算，到方块中心的横向距离约150mm，相同计算约220.8mm；到近侧外表面取130mm也约207.7mm。杆的精确横向安装位置未标尺寸，最终应以场地CAD/实物校正，不能将此近似侧视计算作为所有路径的完整证明。

### 6.3 下一步应解决什么

- 先选车的支承位置和取块路线，画出150mm台阶、300mm高台、杆与完整夹爪的碰撞包络，再定臂根高度、前后位置与臂形。
- 如果从中央高台侧探下取块，要核对夹爪越过高台边缘的路径，不能只把85mm转轴高度加300mm后宣布可达。旧短臂、固定夹爪是否能避开边缘尚未证明。
- 若研究先用被动钩/拨片将块沿杆移向外端，再夹取，这是另一种待验证动作方案；仍要能到达杆根、保持不损坏方块与场地，并保证块脱杆时接得住。
- 不直接加长臂：还受初始260×190×200mm、展开435×400×450mm包络、MG995负载、车体稳定性及洞口姿态约束。60mm轮子也不能默认爬上150mm的竖直台阶。

因此，可以继续保留“同类左右夹爪”作为两种取块的共同末端，但**尚不能声称当前两舵机旧几何已兼容洞内和挂架取块**。解决挂架路径属于接下来总体结构设计的必要部分。

## 7. 样机核验顺序

1. 取得同几何样块并称重；若先自行打印，记录耗材密度、壁数、层高、填充率和实际质量，避免把自制样块当成官方实物。
2. 制作可调倾角的平板/单槽，完成起滑角与连续入槽试验。
3. 用纸板或板材搭70×50mm洞口、约70mm深的模拟件，将40mm方块前表面齐洞口放置，检查左右夹取、后退和抬臂。
4. 用300×300×150mm障碍、300mm高墙及高度250mm的直径14mm、长150mm杆，搭挂架环境；先用纸板臂做路径检查，不急于采购更大舵机。
5. 两种取块动作和入槽姿态通过后，冻结总体机械空间，再定模块底板PCB的板框、安装孔和连接器位置。

待确认的最小信息集：官方道具实测质量/打印参数；洞口三轴尺寸的定义；挂杆精确安装位置；夹爪完整开合外形；简化翻臂是否具备被动姿态保持；真实槽底起滑角。目前没有上述实物验收数据。
