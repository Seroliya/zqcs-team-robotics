# CRTC2026 小车项目

本文件是本项目的长期记忆，记录当前目标、已采用方案、依据、待验证事项与继续工作的入口。团队已确认参加**新生组**，当前优先完成**一辆最小可运行 Demo**，再复制和完善第二辆。

**当前阶段：结构、供电与信号接线设计。尚无已验证的整车、固件工程或正式加工图。** “最终电源图”表示本轮讨论选定的连接方案，不表示已经通过实物测试；信号图为建议引脚分配。

后续工作先读本文件。用户的新指示优先；比赛约束以本地规则原文及后续官方修订为准。旧设计文档与本文件冲突时，使用本文件中的当前方案，不把历史建议恢复成要求。

## 1. 背景、目标与设计原则

- 比赛最终使用两辆车；团队成员是新手，优先结构简单、少采购、容易接线和调试。
- 基本机构为 **MG995 翻转臂＋SG90 夹爪**，底盘采用四个 TT 马达、两块 DRV8833，STM32 核心板与 PS2 手柄控制。
- 当前目标是先打通供电、遥控行驶、翻臂和夹取，再验证固定料槽投放。精确堆满 8 块、过桥和双车协作不是首个上电 Demo 的前置条件。
- 两车优先共用平台，先验证一辆再复制。轮组宽度、料仓排列和具体机械尺寸尚未冻结。
- 电池尽量低置，臂根有独立承力支承；用实际负载验证稳定性，不能只凭三维外观判断可行。
- 电流规格分清“实际耗电”“堵转预算”和“电源输出能力”。不得把额外余量反复叠加成最小 Demo 的硬性采购门槛，也不得把模块商品标题当作已验证能力。

## 4. 当前采用的电源方案

### 4.1 单车器件与连接

单车使用：4 个 TT 马达、2 块 DRV8833、1 个 MG995、1 个 SG90、1 块 STM32F103C8T6 核心板、1 套 PS2 接收器/转接板、1 组两节串联的 18650 电池。

用户已确认所查舵机工作电压为 **4.8–6V**，因此当前统一使用固定 **5V** 供电，不再要求舵机支路必须调到 4.8V。

| 支路 | 当前新增模块 | 负载 |
|---|---|---|
| A：马达 | **固定 5V、持续 5A** 降压模块 ×1 | 两块 DRV8833 的 VM，四个 TT 分别由四个独立 H 桥通道控制 |
| B：舵机与控制 | **固定 5V、持续 3A** 降压模块 ×1 | MG995、SG90、STM32 核心板 5V 入口、PS2 转接板 5V 输入；从模块输出处分支接线 |
| 备用 | 原有小 5V 降压模块 | 暂不接入；若共用 B 支路导致控制系统复位或掉线，再单独供控制系统 |

```text
两节 18650 串联：标称 7.4V，满电 8.4V
  正极 → 近电池保险丝 → 主开关 → 分电
                                 ├ A：5V / 5A
                                 │   ├ DRV8833① → 通道A接马达1、通道B接马达2
                                 │   └ DRV8833② → 通道A接马达3、通道B接马达4
                                 └ B：5V / 3A
                                     ├ MG995
                                     ├ SG90
                                     ├ STM32核心板5V入口 → 板载稳压 → 3.3V → 主控芯片
                                     └ PS2转接板5V输入
  负极 → 公共GND → 降压模块、驱动板、舵机、核心板、PS2转接板的GND
```

- 两个降压模块的**输入**接同一电池分电点；两个模块的**输出正极不得并联**。
- 电机的两根线接它所属 H 桥通道的两个输出端，不直接接降压模块，也不把其中一根线固定接公共地。
- 舵机和控制系统从 B 的输出端分别布线。舵机电流不经过 STM32 板、PS2 板或面包板；供电线与回流线要可靠。
- STM32 **核心板**上的额外稳压器负责 5V 转 3.3V，不能把“STM32 芯片本身”当成能直接接 5V。5V 不接 3V3/VDD 引脚。
- 器材资料写明核心板可从 5V/USB 供电，PS2 转接板有稳压功能；实际端子和板型仍须核对，不能凭示意图中的器件外观接针脚。
- 供电图描述电源与马达输出；舵机 PWM、DRV8833 输入和 PS2 通信线见信号图及4.4节。GPIO仍是建议分配，尚未通过实物和固件验证。

### 4.2 电流依据与适用范围

| 数值 | 来源与使用方式 |
|---|---|
| MG995 堵转电流 **1800mA** | 用户查得；尚未提供原始链接或实测记录，具体测试电压待核对 |
| SG90 堵转电流 **860mA** | 用户查得；同上 |
| 两舵机合计 **2.66A** | 1.80＋0.86，是采用上述数据的同时堵转预算，不是正常运行电流 |
| 控制系统预留 **0.15–0.30A** | 设计估算，未测量 |
| B 支路合计约 **2.81–2.96A** | 条件性预算：上述舵机数据适用于本机 5V 供电时才可直接使用。接近 3A，作为 Demo 试验方案，需验证动态电压与温升 |

堵转电流可用于相同电压下的最大稳态负载预算；不应把同一启动需求再重复相加。它不保证覆盖所有瞬态，也不表示器件可以长期堵转。此前 MG995 2.5A、SG90 0.8A 的估算不再作为当前预算依据。

四个 TT 的当前 5A 支路用于轻载、缓起步 Demo。前期同类 1:48 TT 参考样品在 6V 下空载约 0.16A、堵转约 1.5A；不是本批次在 5V 下的实测参数，不能直接断言比赛爬坡与顶推均足够。

DRV8833电流要按**每个H桥通道**与整板散热分别核对。TI在VM=5V、25℃条件下列出PWP/RTY封装每桥1.5A RMS、2A峰值，PW封装每桥0.5A RMS、2A峰值；这些不是任意红板双通道同时工作的保证值。本车具体封装、PCB散热、限流配置和TT实际电流仍未确认。截图所称“单板统一只有1.2A，两板共2.4A”没有对应板型依据，不采用为统一规格。5V/5A是电源供电能力，不强迫驱动板消耗5A，也不保护某个通道免于过载；四个电机分别走四个通道，不能把总电流当成流过单个通道。DRV8833有过流和过温保护，但不能据此允许长期堵转；也不能把正常启动或一次堵转直接判为必然烧毁。当前保留两板带四马达的轻载Demo方案，持续顶推能力须单独验证。

### 4.3 采购与验证原则

- 先做一辆：新增 **1 块 5V/5A＋1 块 5V/3A**。第二辆复制时再各买一块；采购、到货和模块具体型号均未确认。
- 要求模块在电池满电 8.4V，以及放电后约 6–6.4V 的测试条件下仍能稳定输出 5V。此处是验证区间，不是已确定的电池截止电压。
- “3A/5A”应对应模块实际持续输出条件；芯片最大开关电流、商品峰值与整板持续电流不是同一指标。
- **XL4015 官方输入下限为 8V**，不作为当前两串电池方案的默认选型；增加同款板数量不能解决输入电压不匹配。
- B 支路出现控制复位/遥控掉线时，先定位供电与接线问题，必要时启用原有小降压板单独供控制系统。A 支路实测能力不足时，才考虑拆成每块带两个马达。
- 用户选择先做Demo，再按实测决定是否额外增加滤波／储能电容；不把新增大电解电容一律列为首轮采购前提。上电前仍应核对成品驱动板已有芯片需要的外围元件：TI建议DRV8833的VM就近以至少10μF陶瓷电容接GND，VINT/VCP另有各自配套电容。系统供电图未画出这些元件不表示板上没有；缺失基本外围元件不能等出问题再补，额外储能电容是否足够也不能仅凭外观判断。
- 干扰判断区分欠压与过压：单纯短时欠压通常导致复位或通信异常，不代表烧毁；超过器件额定限制的尖峰可能造成永久损坏，不能把“最多只是STM32掉电”作为验证前提。保持共地并分别布置大电流回路，先轻载缓启停测试；出现复位、抖动或异常发热先停下定位，电压尖峰需示波器等适当测量方法确认。尚无本车瞬态测量结果。
- 电池、保护、主线或 DRV8833 限流/散热不足，不能靠增加降压模块修复。当前图不代表这些器件已验收。

### 4.4 信号接线建议

采用[简洁版信号图](output/signals/robot-demo-signal-wiring-simple-v1.png)。用户偏好简单、少装饰的接线图。图内各分区均连接**同一块 STM32F103C8T6 核心板**；引脚名称不表示排针物理顺序。以下分配利用芯片默认定时器映射，不启用对应定时器的引脚重映射；未确认实际核心板是否全部引出这些引脚。

| STM32引脚 | 连接端 | 信号方向／建议功能 |
|---|---|---|
| PA0 | DRV8833① AIN1 | 输出，TIM2_CH1 |
| PA1 | DRV8833① AIN2 | 输出，TIM2_CH2 |
| PA2 | DRV8833① BIN1 | 输出，TIM2_CH3 |
| PA3 | DRV8833① BIN2 | 输出，TIM2_CH4 |
| PA6 | DRV8833② AIN1 | 输出，TIM3_CH1 |
| PA7 | DRV8833② AIN2 | 输出，TIM3_CH2 |
| PB0 | DRV8833② BIN1 | 输出，TIM3_CH3 |
| PB1 | DRV8833② BIN2 | 输出，TIM3_CH4 |
| PB6 | MG995 的 S | 输出，TIM4_CH1，翻转臂 PWM |
| PB7 | SG90 的 S | 输出，TIM4_CH2，夹爪 PWM |
| PB14 | PS2 DI/DAT，接收器① | **输入**，接收器 → STM32 |
| PB15 | PS2 DO/CMD，接收器② | 输出，STM32 → 接收器 |
| PB12 | PS2 CS/SEL（也称ATT），接收器⑥ | 输出，低电平选中 |
| PB13 | PS2 CLK，接收器⑦ | 输出，由STM32提供时钟 |

- **驱动板：**①的A/B通道分别接马达1/2，②分别接马达3/4。GPIO接AIN/BIN输入，马达接各自AOUT/BOUT输出。3.3V逻辑满足DRV8833输入高电平门限；不能由此推断所有外围模块都支持相同电平。
- **nSLEEP：**运行时必须为高电平；芯片本身有下拉，不能默认悬空也能运行。先查实际驱动小板是否已上拉或固定接高；若需外控且不存在板载固定电平冲突，可预留PA8控制两板。未确认板型前不将该可选线画成必接线。
- **舵机接口：**按用户照片，G是黑色或棕色、V是红色、S是白色或橙色。两种线色不强行对应到具体舵机型号。V接B路5V，G接公共地，S分别接PB6/PB7；舵机供电电流不经过核心板。PWM可从50Hz开始，脉宽和行程按实际机构校准；3.3V控制信号是否被本批舵机可靠识别需实测。
- **PS2接口：**按用户照片的接收器正面朝向编号，④为GND、⑤为VDD，③⑧⑨未使用。9针插座编号不能直接当成6针转接板排针顺序，应按转接板丝印对应DAT/CMD/SEL/CLK/GND/电源入口。
- **PS2电源：**用户照片写接收器VDD允许3–5V；《器材参数.docx》中的转接板资料另写有板载3.3V稳压。当前按B路5V接该转接板电源入口，再由其稳压供接收器⑤VDD 3.3V绘图；不把接收器⑤误标为转接板5V入口。实际板型不同应重新核对。资料所称保护电阻不等同于已证明具有电平转换，DAT实际电平及上拉配置仍需确认。
- **固件预留：**PA13/SWDIO、PA14/SWCLK留给下载调试；没有第三只分料舵机。PS2先可用GPIO模拟通信，确认协议时序后再决定是否用硬件SPI；马达PWM使用TIM2/TIM3，舵机PWM使用TIM4，避免将马达频率和舵机帧频混用。
- **接线验收：**所有模块共地；逐根核对14根主信号线及驱动使能状态，再分别测试马达、舵机和手柄。图纸核对完成不等于已完成上电验证。

### 4.5 车内接线与模块底板（建议，未定案）

用户指出车内空间有限，散线整理及公共地连接困难。当前建议桌面单模块调试仍可手工连接，装车优先考虑简单的双层模块底板PCB：保留现成STM32核心板、两块DRV8833、降压模块和PS2转接板，用插座、端子及PCB走线集中连接；不是重新设计各裸芯片电路。用户尚未确认开始正式PCB设计。

共地表示各GND电气连通，不要求所有地线焊到同一个物理点。底板应提供连续、低阻的地连接，并按布局安排马达和舵机的大电流回路，避免经过核心板的细地线；A路5V与B路5V输出正极仍须分开。模块电源触点、铜线、过孔及端子都需按实际电流选型，不能认为铺铜后自然满足5A。

底板可集中两只舵机G/V/S接口、四个马达双线接口、PS2接口和SWD接口，并预留可选电容焊盘。降压模块是否装在同板、板框大小和插座位置，须取得实际模块尺寸、引脚顺序、安装高度以及底盘可用空间后确定；目前没有可制造PCB文件。

## 5. 机械方案的当前状态

**已经明确的方向：** 保留翻转臂＋夹爪，去掉复杂的回转分料机构及分料舵机，优先研究固定的纵向倾斜导料槽，通过翻转臂不同角度改变前后投放位置。原三维模型仍展示旧主动分料结构，不能作为当前加工依据。

**仍未定案的部分：**

- 用户提出 **2×2×2 堆叠、共 8 块** 的目标。固定单轴翻转臂能改变前后位置和高度，不能独立选择左右两列；不能承诺只靠投放角度就实现整齐 2×2×2。
- 助手提出过 **前后4×左右1×上下2** 的 8 块长槽备选，以及先验证单层4块再试第二层的顺序；用户尚未明确确认该排列，不能记作最终布局。
- 料槽倾角、挡边高度、净宽、实际容量、夹爪退出间隙及各投料角，均待样件验证。改变翻臂角度同时改变水平位置和高度，不是独立升降。
- 用户倾向两车统一、轮组适当收窄。此前 135/185mm 是可视化比较值，135–140mm 是过桥设计候选，不是已测尺寸或最终轮宽。
- 臂根约85mm、臂长约180mm、车体约250×185mm等均来自旧概念布局。简化机构后应重新检查，不能直接下单加工。
- 电池低置；分别检查空载、装块、抬臂时的重心与支撑范围。八块两层堆放对高度、重心和行驶保块的影响尚未验证。

两车的具体资源分工、每车常态携带数量和最终仓容，等第一辆可运行样机验证后再确定。低速顶推是曾讨论的兼用方向，主动铲翻不作为已确认功能或当前 Demo 要求。

### 5.1 方块、导料与取块路径的核算结论

详细公式、依据、假设和试验方法见[方块核算报告](output/mechanics/block-gripping-study-v1.md)。以下为2026-09-16核对本地规则第13–17页后的结论：

- **几何与质量：**规则图是六面开孔的立体框架，外40mm、孔约20mm，未倒角名义棱条宽10mm。用户确认PLA材质，但未给打印填充率、壁数和倒角尺寸。按全部棱条实心、无倒角、参考密度1.24g/cm³计算，体积32cm³、单块39.68g、8块317.44g。当前可用约40g/块作普通PLA的初步负载估算，不是实测值；此前30g仅为示例，不能作为已知质量。不能直接用40³−20³计算六面开孔框架，也不能直接用整块质量乘切片填充率。
- **摩擦：**导料槽材质未定。理想单底面接触时起滑要求tanθ＞μs，质量在判据中抵消。μs假设0.3/0.4/0.5/0.6时临界角约16.7°/21.8°/26.6°/31.0°；这些不是材料实测系数。先用真实样块及候选底板测倾斜起滑角，再确定角度。槽底连续平整，并验证方块孔边、接缝及多块相互卡住；倾斜槽不能自动保证2×2×2堆叠。
- **洞口取块：**规则写洞穴70×70×50mm、方块外平面齐洞口、径向居中；宽70、深70、高50mm是本次计算的轴向解释，仍应核对实物。左右薄夹指有空间：例如内开口50mm、两侧各4mm，外宽58mm。应夹实体棱、保持低位先直线退车约45–50mm，方块完全离洞后再抬臂；不假设底下有托钩间隙。进入部分包络、橡胶垫、连杆与姿态要一起验证，不能仅凭夹爪开口尺寸判定整机可行。
- **挂架取块：**杆直径14mm、长150mm、轴高250mm；图中块位于靠高台墙的杆根，下方有300×300mm、高150mm台阶。方块必须沿杆滑向自由端并完全脱杆，不能直接向上提。旧转轴高85mm、有效半径180mm在目标高度247–250mm时仅剩约72–78mm水平伸距，不能从地面直接跨过该台阶夹到杆根。必须先明确支承位置、接近路线、退杆行程及碰撞包络，不把臂加长到某距离当作已解决。
- **机构与总体布局：**旧稿曾有被动平行四边形保持夹爪姿态，简化方案是否保留尚未确认；刚性单臂的夹爪姿态随角度变化，洞内和挂架两种工况都要检验。先完成取块与入槽的机械路径和空间检查，再冻结模块底板PCB外形及连接器位置。

## 6. 工作流程、运行与验收

当前没有可运行固件。下一阶段按以下顺序推进；代码创建后在本节补充实际运行命令，不预先编造工具链。

| 阶段 | 工作与验收标准 |
|---|---|
| 1. 实物核对 | 记录降压板型号、输入范围、持续电流条件，核对核心板与PS2输入端；确认电池、驱动板和线材实际到货情况 |
| 2. 电源台架 | 先断开负载调试/测量，再逐项接入。两路均为5V；负载动作时无反复保护、明显掉压或异常发热 |
| 3. 基础固件 | 确认开发环境和引脚；保留SWD调试。先完成PS2读取，再分别测试每个马达与舵机方向及行程。上电和遥控失联时应停止轮驱动 |
| 4. 行驶 Demo | 先架空轮子检查四通道，再轻载落地验证前进、后退和转向；缓起步，避免直接高速反转 |
| 5. 翻臂与夹取 | 先空臂、再装实际夹爪和方块，验证夹取、抬升、释放与退出；不长期顶住机械限位，不把堵转当正常工作方式 |
| 6. 联动验收 | 马达启动与翻臂动作期间，STM32不复位、PS2不掉线、舵机无异常动作；失败时定位电源/驱动/程序原因，不仅凭“电流够大”判断 |
| 7. 简单料槽 | 至少完成实际方块的夹取与入槽，再验证多位置投放、层间干涉和行驶时不易掉块。8块满仓暂不作为首个Demo必达项 |
| 8. 比赛完善 | 冻结尺寸和质量，完成轮组过桥、坡道、官方遥控断电、结构强度及预算检查，再复制第二辆并练习协作 |

每次实测至少记录：供电电压、器件型号、负载/动作、输出端及负载端电压、测量方法、是否复位/掉线/过热。电流数据注明空载、典型负载或堵转条件；普通万用表平均读数不能当作捕获全部瞬态的证据。
